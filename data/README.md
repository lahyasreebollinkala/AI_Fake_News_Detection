# Data

```
data/
├── sample_dataset.csv   # 5,000-row unified sample of all sources (versioned)
├── Fake.csv             # (deleted, ~63 MB) raw fake-news articles
├── True.csv             # (deleted, ~54 MB) raw real-news articles
├── GlobalFakeNews_Research2026_v1.csv  # (deleted, ~117 MB) merged + engineered features
└── cleaned_news.csv     # (deleted, ~197 MB) NLP-cleaned training data
```

## Overview

The model is trained on a corpus of real vs. fake news articles. The four
original files are a single pipeline chain:

```
Fake.csv + True.csv
   │  src/prepare_dataset.py (concat, label, full_text, 5 engineered features)
   ▼
GlobalFakeNews_Research2026_v1.csv
   │  src/preprocessing.py (NLP cleaning -> clean_text)
   ▼
cleaned_news.csv   <-- final training data
```

`sample_dataset.csv` is a 2,000-row stratified sample (per source and label,
seeded for reproducibility). It unifies data from all four files, drops
duplicate articles (~859 duplicate `title`+`text` rows removed) and keeps the
pipeline's input reproducible in git while staying small enough to bundle.

## Columns

| Column                | Description                                          |
|-----------------------|------------------------------------------------------|
| `title`               | Article headline (from Fake.csv / True.csv)          |
| `text`                | Article body (from Fake.csv / True.csv)              |
| `subject`             | Article subject/category (from Fake.csv / True.csv)  |
| `date`                | Publish date (from Fake.csv / True.csv)              |
| `source_dataset`      | `fake`, `true`, or `unknown` (not matched to current raw files) |
| `label`               | `0` = real, `1` = fake                               |
| `full_text`           | `title + ". " + text`                                |
| `sentiment_score`     | Engineered text-sentiment feature                    |
| `clickbait_score`     | Engineered clickbait feature                         |
| `emotional_word_ratio`| Ratio of emotional words                             |
| `readability_score`   | Text readability score                               |
| `source_trust_score`  | Source credibility feature                           |
| `clean_text`          | NLP-cleaned `full_text` (lowercased, URLs/HTML/numbers/punctuation removed, stopwords removed, lemmatized) |

## Dataset statistics (full data, before deletion)

| File                                  | Rows   | Columns |
|---------------------------------------|-------:|---------|
| `Fake.csv`                            | 23,481 | 4       |
| `True.csv`                            | 21,417 | 4       |
| `GlobalFakeNews_Research2026_v1.csv`  | 44,898 | 7       |
| `cleaned_news.csv`                    | 44,898 | 8       |

- Label distribution: `1` (fake) = 23,481, `0` (real) = 21,417.
- `cleaned_news.csv` has 9 missing `clean_text` values (empty after cleaning).
- About 7,216 rows in `GlobalFakeNews_Research2026_v1.csv` / `cleaned_news.csv`
  could not be matched (by title) to the current `Fake.csv` / `True.csv`; these
  are labeled `unknown` in the sample. They likely come from an earlier version
  of the raw files used to generate the derived dataset.

## Provenance

- `Fake.csv` and `True.csv` come from the public **"Fake and Real News
  Dataset"** (Ahmed, Traore & Saad, 2017) distributed on Kaggle.
- `GlobalFakeNews_Research2026_v1.csv` is generated by
  `src/prepare_dataset.py`.
- `cleaned_news.csv` is generated by `src/preprocessing.py`.

## Regenerating the deleted files

The four large CSVs were removed to save disk space (~430 MB). To regenerate:

1. Re-download `Fake.csv` and `True.csv` from Kaggle into `data/`.
2. Run `python -m src.prepare_dataset` from the project root -> `GlobalFakeNews_Research2026_v1.csv`.
3. Run `python -m src.preprocessing` -> `cleaned_news.csv`.

The trained artifacts in `models/` (`best_model.pkl`, `vectorizer.pkl`,
train/test splits) do not depend on the CSV files and keep the app working.
