# Data

## What ships in the repository

| File | Size | Status |
|---|---:|---|
| `sample_dataset.csv` | ~13 MB | **Versioned.** The only dataset committed to git. |
| `GlobalFakeNews_Research2026_v1.csv` | ~10 MB | Generated by `python -m src.prepare_dataset`. Git-ignored. |
| `cleaned_news.csv` | ~13 MB | Generated by `python -m src.preprocessing`. Git-ignored. |
| `Fake.csv`, `True.csv` | ~117 MB | Optional full-size sources. Git-ignored. |

## The pipeline chain

```
Fake.csv + True.csv              (optional; 44,898 rows)
        |  fallback when absent
        v
sample_dataset.csv               (2,000-row stratified sample, committed)
        |
        |  python -m src.prepare_dataset
        v
GlobalFakeNews_Research2026_v1.csv    merged, de-duplicated, labelled, engineered
        |
        |  python -m src.preprocessing
        v
cleaned_news.csv                 NLP-cleaned training data
        |
        |  python -m src.feature_engineering
        v
models/train_documents.pkl       stratified 80/20 split, materialised
models/test_documents.pkl        BEFORE any vectoriser is fitted
```

`src/data_loader.py` prefers `Fake.csv` and `True.csv` whenever they are
present in `data/`, and falls back to `sample_dataset.csv` otherwise. Both
schemas are normalised to the same columns, so switching to the full dataset
needs no code change -- drop the two files in and re-run the pipeline.

## The bundled sample

`sample_dataset.csv` is a seeded, stratified sample drawn across every source
and both labels, so the pipeline is reproducible in git without a 117 MB
download. Duplicate `title` + `text` pairs are removed during preparation.

The 2,000 sampled rows become **1,999** prepared articles after de-duplication:

| Class | Label | Rows | Share |
|---|---:|---:|---:|
| Real | `0` | 836 | 41.8% |
| Fake | `1` | 1,163 | 58.2% |
| **Total** | | **1,999** | |

Two of those 1,999 articles contain no tokens once URLs, digits, punctuation,
stopwords and one- and two-character fragments are removed, so they are dropped
when the split is drawn. That leaves **1,997 usable documents**, reconciled as:

| Stage | Rows |
|---|---:|
| Sampled source rows | 2,000 |
| Removed as duplicates | 1 |
| Prepared articles | 1,999 |
| Dropped for cleaning to empty text | 2 |
| **Usable documents** | **1,997** |
| — training split | 1,597 |
| — hold-out split | 400 |

The hold-out holds 167 real and 233 fabricated articles. Every one of these
counts is re-derived from the artifacts by the pipeline and asserted in
`tests/test_metrics_contract.py`, so they cannot go stale silently.

## Columns

| Column | Description |
|---|---|
| `title` | Article headline |
| `text` | Article body |
| `subject` | News desk / category |
| `date` | Publish date |
| `source_dataset` | `fake`, `true`, or `unknown` |
| `label` | `0` = real, `1` = fake |
| `full_text` | `title + ". " + text` -- the string the model actually reads |
| `sentiment_score` | Engineered: negative values read as hostile framing |
| `clickbait_score` | Engineered: headline phrasing, shouting, exclamation marks |
| `emotional_word_ratio` | Engineered: share of loaded, alarmist vocabulary |
| `readability_score` | Engineered: Flesch Reading Ease, higher is plainer |
| `source_trust_score` | Engineered: neutral prior; the corpus carries no publisher identity |
| `clean_text` | `full_text` after the NLP cleaning chain |

The five engineered scores are computed for auditability and shown in the UI.
The classifier reads text only — every benchmark is run over the three
representations built from `clean_text`, and the five scores are never fed to
any model — so the reported figures measure the text model rather than
hand-written rules.

## Provenance

- `Fake.csv` / `True.csv`: the public **Fake and Real News Dataset**
  (Ahmed, Traore & Saad, 2017), distributed on Kaggle.
- `sample_dataset.csv`: a seeded stratified sample of the above, committed so
  the project is reproducible without the large downloads.
- The two derived CSVs are regenerated by the scripts in `src/`.

## Rebuilding

```bash
python -m src.prepare_dataset      # -> GlobalFakeNews_Research2026_v1.csv
python -m src.preprocessing        # -> cleaned_news.csv
python -m src.feature_engineering  # -> models/{train,test}_documents.pkl
python -m src.train_models         # -> models/*.pkl, results/model_metrics.json
python -m src.evaluate_models      # -> images/
python -m src.eda                  # -> results/dataset_profile.json
python -m src.eda_visualization    # -> images/
python -m src.report               # -> docs/ieee_report.{md,tex,html,pdf}
```
